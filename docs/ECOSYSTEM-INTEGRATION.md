# LibreCoding — Ecosystem Integration

Status: planning document for a learning/community platform.

## Product boundaries
- Keep lessons and exercises accessible without paid unlock requirements.
- Separate public learning content from private account data.
- Apply moderation and reporting controls to community features.
- Never execute learner code on the web server without an isolated execution design and resource limits.
- Make age-appropriate privacy defaults and data deletion behavior explicit.

## Next tasks
1. Document the lesson, exercise and progress data model.
2. Define safe code-execution isolation before enabling browser execution.
3. Add tests for access control and user-owned content.
4. Document moderation, reporting and account deletion flows.
